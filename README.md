# Masary

**Masary** is a modern web application that helps individuals effectively manage their personal finances by tracking both income and expenses. The name _Masary_ is derived from an informal Arabic word for "money," widely used across Arab countries.

## Features:
- Track income sources.
- Log and categorize expenses.
- Visualize spending patterns with intuitive charts and graphs.
- User authentication for secure personal access.
- Responsive UI for desktop and mobile usage.

## Tech Stack:

### Frontend
- React.js
- Recharts

### Backend
- Node.js
- Express.js
- MongoDB

## Deployment: 
- Frontend deployed on Vercel (masary.vercel.app)
- Backend deployed on Koyeb
